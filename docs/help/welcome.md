# FlowCode
FlowCode is the visual IDE for the TernOO-5500FP balanced-ternary computer. Work
happens in tabs across the top; some tabs hide the sidebar and Output when they run
self-contained.

# The tabs
Start with [[flow|the Flow canvas]] — the heart of the IDE — or open the
[[mesh|Mesh tab]] to trade compute. See [[ternoo-words|the word model]] for the
substrate beneath it all.
