The Documentation tab
section: The tabs

This is the help you're reading now. It's built into TernOO rather than kept in a manual somewhere else — every tab has a **? Help** button that opens the right page here, and the pages are threaded together so one idea leads to the next.

## Finding your way

The topics are listed to one side, grouped into sections. A search box finds any page by a word from its title or body, so if a phrase stuck with you, you can get back to it. The page you're reading fills the rest.

The highlighted words in a page take you to related topics, and you can move back and forward through the pages you've visited. Follow the links where they lead — the documentation is meant to be read by wandering, not just looked up.

## If a link looks greyed out

A greyed-out link points to a page that hasn't been written yet. TernOO shows these rather than hiding them, so the documentation can always see its own gaps and fill them over time.
