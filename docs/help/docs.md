The Documentation tab
section: Tabs

This tab is the help system you're reading right now. It's part of the product, not a manual off to the side — every tab has a **? Help** button that opens the right page here, and everything is cross-linked so you can follow a thread of ideas rather than hunt through an index.

## Finding your way

The left side lists the topics, grouped into sections — concepts, tabs, and more. The search box does a plain text search across titles and content, so if you remember a word from a page, you can find it again. The right side shows the page you're reading.

Links inside a page (the highlighted words) jump you to related topics, and you can go **back** and **forward** through the pages you've visited, like a browser. Follow the links — the documentation is built to be wandered, not just looked up.

## How the help is written

Pages are plain text files in a small, readable format — a documentation writer can edit them without touching any code, and adding a page is as simple as adding a file. If you ever see a **dead link** (greyed out), it means a page hasn't been written yet; the system flags these rather than hiding them, so the documentation can always see its own gaps.
